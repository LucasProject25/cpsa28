# CPSA28 - Projet individuel 
## Certification - Développeur Web et Web Mobile

Ce projet est un projet individuel réalisé lors de ma formation pour acquérir ma certification de développeur web et web mobile (*équivalent à un Bac +2*).

### But du projet
Pour valider ma certification ainsi que le projet, il fallait trouver un site internet puis en faire une total refonte graphique, sur WordPress, en plus d'ajouter des fonctionnalités énoncés par les formateurs après l'analyse du site
initial. 

### Site choisi
Le site est un showroom de vente de voiture haut de gammes d'occasion situé à Fontenay-Sur-Eure.

### Langages utilisés
- HTML/CSS/JS : Front-End
- (My)SQL/PHP : Back-End

### Logiciels utilisés
- Figma : Maquette
- CRM : WordPress
- Visual Studio : Programmation
- PhpMyAdmin : Table SQL

### Fonctionnalité du site initial
- Catalogue de véhicule
- Recherche personnalisé

### Fonctionnalités ajoutés par rapport au site initial
***Client***\
**Accès & Authentification**
- Espace client privé
- Compte validé manuellement

**Catalogue & Recherche**
- Avant-première véhicules exclusifs
- Demande de recherche personnalisée via critères spécifiques

**Suivi & Communication**
- Tableau de bord personnel
- Conseiller attitré (par demande)
- Rendez-vous privé
- Visioconférence/Présentiel (liste déroulante)

**Fidélité & Privilèges**
- Statut membre
- Accès prioritaire
- Événements privés (une page spécial dans l'espace client)
- Conciergerie

***Administrateur : CRUD***
**Gestion membre :** 
- Validation manuelle
- Statut (Standard / Premium / VIP) 
- Affectation conseiller

**Gestion des demandes :**
- Suivi & annotations
- Dépôt de documents 
- Propositions de véhicules

**Catalogue exclusif**
- Véhicules membres uniquement

**Agenda & Rendez-vous**
- Planification 
- Créneaux privés 
- Présentiel / Visioconférence 

**Fidélité & Paramétrage**
- Avantages débloqués (Seulement affiché dans l'espace client)
- Suivi des privilèges
